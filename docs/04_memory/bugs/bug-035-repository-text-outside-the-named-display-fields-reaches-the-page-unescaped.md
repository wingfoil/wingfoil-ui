## Summary

Repository text that the API serves for display, outside the fields spec-004 §5 names (element
titles, pattern references, the `ui.yaml` strings), reaches the page without the character escape
`neutralise`: a bidi or control character committed in it is served raw.

## Steps to Reproduce

1. A project whose committed DNA (`.wingfoil/dna.yaml`) holds U+202E in the project name and in a
   member's name, and a directive whose `title` holds it.
2. `GET /api/p/:pid`, `GET /api/p/:pid/config`, the directives list and the Memory list, with the
   session.

## Expected Behavior

Every display string a read body takes from the repository passes through `neutralise`
(`server/src/git/redact.ts`), as spec-004 §5 states for the class; keys (ids, types, states) stay
raw.

## Actual Behavior

These fields are returned as the CLI or git gives them (task-056's enumeration, class (r)): the DNA
texts (the project name in the header and the project list, member names and emails in `identity`
and in the descriptor's actor, `/config` `dna`), the directives' `name` and `title`, the 0.2.x
workflow texts and the 0.3.x workflow `description`, the file tree's `name`, the project list's
`remote`. task-056's review added (2026-11-07): the documentation pages' paths, the history's
`from` and `to`, and the directive page's heading.
