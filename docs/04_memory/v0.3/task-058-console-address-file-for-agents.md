## Description

dl-012 R1 by adr-003 D1–D5 (RP3-14 D4, RP3-15 F3, RP3-17 A3–A6, C2): each console writes an
address file, so that an agent of a project can build a working link to an element without the
token and without asking the user.

- `consoles/<port>.json` in the state directory (spec-006 §1, `WINGFOIL_UI_STATE_DIR` included),
  folder `0700`, file `0600` (POSIX; on Windows the access list of `%APPDATA%`, A6), with the shape
  of `contracts/state/console-address.schema.json` (`format`, `url`, `port`, `portFixed`, `pid`,
  `host`, `started`, `version`) and never a token, a session, a project path or id (D5);
- written atomically **after listening and before the URL line**; a heartbeat refreshes its
  modification time every 10 s and rewrites it when it is gone or names another console (D2);
- **stale** when its `pid` is dead on this host or its modification time is older than 30 s; the
  start housekeeping removes this host's files only when their `pid` is dead, other hosts' files by
  age, and dead writers' temporary files (D3);
- removed as the first stop step, after the heartbeat stops, and again by the exit handler (D2);
- how an agent uses it — `state.json` read-only for the project id, the liveness check, the link
  form of spec-011 (D4, A3) — documented in `docs/cli-reference.md`.
