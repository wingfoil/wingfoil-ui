# Definition of Done

An item is done when it meets every rule below; until then it is not part of the Increment. A
project replaces these rules with its own by a `custom/` directive of the same id.

- The work meets the project's quality measures: its tests, checks and reviews pass.
- It is integrated with the rest of the product, with no step left for later.
- It is verified as the project requires, and a reviewer other than its author has checked it.
- What a user or an operator needs to know about it is written down.
